# 엑셀자 📏

엑셀처럼 셀이 많은 화면에서 지금 보는 행/열이 헷갈리지 않게, 화면 위에 반투명 띠를 띄워 주는 macOS 메뉴바 앱입니다.

## 설치

- **도구함**이 있으면 '개발자 앱' 탭에서 엑셀자를 눌러 받으면 끝이에요.
- 직접 받기: [Releases](https://github.com/SsackTeun/excel-ruler/releases/latest) 에서 `ExcelRuler.zip` 을 받아 압축을 풀고 Applications 폴더로.
- 소스에서 빌드: `./build.sh` → `~/Applications/엑셀자.app` (Xcode Command Line Tools 필요)

macOS 12 이상, 애플 실리콘 · 인텔 모두.

## 새 버전 올리기

```bash
./release.sh 1.1
```

## 사용법

| 단축키 | 동작 |
|---|---|
| ⌃⌥F | 마우스 따라가기 ↔ 고정 |
| ⌃⌥M | 가로(행) → 세로(열) → 십자 전환 |
| ⌃⌥R | 숨기기 / 보이기 |

- 따라가기 모드: 띠가 마우스를 따라다니고, 클릭은 아래 앱으로 그대로 통과합니다.
- 고정 모드: 띠를 끌어서 이동, 휠로 두께 조절, 방향키 1px 이동, ⇧+방향키 한 칸 이동, esc 로 따라가기 복귀.
- 메뉴바 📏 에서 색·진하기·두께 변경. 설정은 자동 저장됩니다.
